# Contributing

Bug reports, documentation and focused pull requests are welcome. Include WordPress/PHP versions, theme, reproduction steps and expected behavior. Use a local or staging site and redact private data.

For changes, run the build, JavaScript tests, PHP tests and packaging commands listed in README.md. Keep generated block files synchronized with their source. New behavior should preserve existing settings, be optional when it changes appearance, and support keyboard and mobile use. Use WordPress capabilities, nonces, sanitization, escaping and translation functions for new admin interfaces.

Do not commit credentials, customer data, client starter content or unrelated builds. Contributions are licensed under GPL-2.0-or-later. WordPress.org releases require maintainer review and a passing release validation process.
